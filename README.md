# Markdown Блог

Статический блог на чистом JavaScript с собственным парсером Markdown и клиентской маршрутизацией.

## Технологии

- Чистый JavaScript (ES6+)
- Собственный парсер Markdown на регулярных выражениях
- Маршрутизация через hashchange
- fetch() + async/await
- localStorage

## Функциональность

- Парсинг Markdown (заголовки, жирный, курсив, код, ссылки, списки)
- Кэширование статей
- Избранные статьи (localStorage)
- Счётчик времени чтения
- Кнопка "Копировать код"
- Поиск по статьям
- Тёмная тема
- Адаптивный дизайн
