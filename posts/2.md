# Клиентская маршрутизация в SPA

Одностраничные приложения (SPA) загружают один HTML-файл и динамически обновляют контент без перезагрузки страницы. **Маршрутизация** — это механизм, который связывает URL с определённым состоянием приложения.

## Как это работает?

Есть два основных подхода к клиентской маршрутизации:

1. **hashchange** — использует хеш (#) в URL
2. **History API** — использует pushState и заменяет URL без хеша

## Hashchange (простой способ)

Хеш никогда не отправляется на сервер, поэтому его изменение не вызывает перезагрузку:

```javascript
window.addEventListener('hashchange', () => {
    const hash = window.location.hash;
    
    if (hash === '#/about') {
        renderAbout();
    } else if (hash === '#/contact') {
        renderContact();
    } else {
        renderHome();
    }
});

function navigate(hash) {
    window.location.hash = hash;
}
```
