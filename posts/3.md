# Регулярные выражения для парсинга Markdown

**Регулярные выражения (regex)** — это мощный инструмент для поиска и замены текста по шаблону.

## Основы синтаксиса

```javascript
/\d+/          // одна и более цифр
/\w+/          // одна и более букв
/\s+/          // пробельные символы
/^/            // начало строки
/$/            // конец строки
/*/            // 0 и более раз
/+/            // 1 и более раз
/?/            // 0 или 1 раз
```
