# Введение в JavaScript

**JavaScript** — это язык программирования, который оживляет веб-страницы. Вместе с HTML и CSS он является одной из трёх основных технологий World Wide Web.

## Переменные и типы данных

В JavaScript переменные объявляются с помощью `let`, `const` или `var`:

```javascript
// Современный способ
let name = "Анна";
const age = 25;
var oldWay = "Устаревший"; // лучше не использовать

// Типы данных
let string = "Текст";
let number = 42;
let boolean = true;
let array = [1, 2, 3];
let object = { key: "value" };
